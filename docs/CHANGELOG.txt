# Changelog

All notable changes to the Mitra Kinerja application are documented in this file.
The format is based on Keep a Changelog, and this project adheres to Semantic Versioning.

## [2.7.9] - 2026-10-30
### Added
- Single consolidated master database (`database/mitra_kinerja.sql`) with 100% baseline parity across all 21 partnerships.
- Hairline top progress indicator for seamless navigation feedback.
- GPU-accelerated enter glides for fluid 60 FPS page transitions.
- Automated script cache-busting on client assets.

### Fixed
- Modal hierarchy and DOM container boundaries on the portfolio management interface.
- Client-side chart instance lifecycle teardown preventing detached canvas memory leaks.
- Rate-limiting boundary checks and HTTP manifest download restrictions.

## [2.7.0] - 2026-10-27
### Added
- Integrated partner creation and document management inside the portfolio view.
- Multi-field filtering and dynamic pagination controls across data ledgers.
- Turnkey Windows WLAN server launchers with dynamic port and Wi-Fi IP discovery.

### Changed
- Standardized empty-state typography and minimalist SVG outline icons.
- Streamlined Gate 0 screening lifecycle and draft submission workflows.

## [2.5.0] - 2026-10-08
### Added
- Scorecard Result-Chain V3 architecture (7 core evaluation indicators).
- 12-Element Baseline tracking ledger with document lock guards.
- Early Warning System (EWS) monitoring across 4 risk dimensions.
- Dual-OS deployment compatibility for Windows XAMPP and Linux environments.

## [1.0.0] - 2026-09-22
### Added
- Initial baseline repository import with database schema and seed data for partnership agreements.
- Core scorecard assessment engine based on PKN I 2026 guidelines.
- Authentication system with role-based access control (Admin, Pemeriksa, Validator, Pimpinan, Pengampu, PIC).
